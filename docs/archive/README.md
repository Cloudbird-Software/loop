# docs/archive —— 只读归档

本目录存放已完成使命的一次性产物：设计手册原稿、agent 会话转录、发版说明、
沙盒填写卡、PR 正文草稿等。

**它们从根目录移到这里的原因**：进仓 AI 读根目录时，这些文件（合计约 230KB）
是纯噪声，会挤占上下文并制造"哪份才是权威"的歧义。对应
`docs/审查裁决-2026-07-30.md` 中裁定为 TRUE 的 P2-15。

## 规则

- 本目录**只读**。任何机制、workflow、提示词都不得从这里读取运行时配置。
- 权威文档在根目录与 `docs/`：`CHARTER.md`（章程）、`DECISIONS.md`（ADR）、
  `policy.yml`（方向盘）、`ROUTING.yaml`（路由）、`UPSTREAM.yaml`（供应链）。
- 归档文件中如仍有活的知识，应先摘录进正式文档，再让归档保持不变。
