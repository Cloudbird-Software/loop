### Scenario B — 依赖放行（acceptance #2）

- 步骤：
  1. 在 product-x 开 issue #63 "V-006 test upstream dep" → 立刻 PATCH state=closed（state_reason=completed）。

- 期望：tick `[3] Unblock dependencies` 应打 `→ #64 unblocked (all deps merged)`，#64 state: blocked → ready。
- 实际：`[3] Unblock dependencies...` 行后**没有任何 `unblocked` 输出**。复检 #64 仍 `state=blocked, blocked_by=[63]`。
- 根因（客观）：`gh issue view 63 -R Cloudbird-Software/product-x --json state` 返回 `{"state":"CLOSED"}`（**大写**）。tick.py:212 比较 `if st != "closed":`（小写），永远不匹配 → `all_merged=False` → 跳过 write_block。
- 客观复现：
  ```
  $ gh issue view 63 -R Cloudbird-Software/product-x --json state
  {"state":"CLOSED"}
  $ gh issue view 63 -R Cloudbird-Software/product-x --json state --jq '.state'
  CLOSED
  ```
- 修复点：tick.py:212 应改为 `if st.lower() != "closed":`，或 `st = json.loads(...).get("state","").lower()`。
