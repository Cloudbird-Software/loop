# C-009 — 8 个 gate 接进 product-x branch ruleset

```yaml
id: C-009
title: 8 个 gate 接进 product-x branch ruleset（require status checks）
type: Card
role: impl
tier: standard
charter: ["G0"]
paths:
  - gates/
  - product-x/.github/
acceptance:
  - product-x branch ruleset 的 "Require status checks" 列表非空
  - 至少 4 个 gate 接入（不全接也行，先接 critical 的）
  - 开一个不带 gate 的 PR，确认被 ruleset 拦下
  - ruleset 配置记录在 cards/ 评论或 product-x/SETTINGS.md
depends_on: [C-007]
ready: false
status: pending
```

## 前置依赖检查

- [C-007](./C-007.md) 必须先 done（contracts + verify.sh，gate 才有东西可查）。
- 若 C-007 未 done → **不要开始**，在卡底评论"等 C-007"。

## 背景

[gates/](../gates) 8 个 gate 代码都在，但 product-x branch ruleset "Require status checks" 还是空的（OPC v4 Day 0 步骤 8，人工未做）。后果：PR 能不带 gate 就合并。不阻塞"跑通"但阻塞"安全跑通"。本卡是 [C-013](./C-013.md) 扩池的前置之一（并发场景下 gate 是最后防线）。

## 要做什么

1. 等 [C-007](./C-007.md) done。
2. 在 product-x Settings → Branches → Branch protection rules 配 ruleset。
3. "Require status checks" 勾选至少 4 个 gate（建议：lint、test、verify、charter-check）。
4. 开一个测试 PR 故意不带 gate（如跳过 CI），确认被 ruleset 拦下。
5. 把 ruleset 配置截图/文字记录在卡底评论或 `product-x/SETTINGS.md`。

## 不要做什么

- 不要全接 8 个 gate（先接 4 个 critical 的，避免 noise）。
- 不要把 ruleset 设成 "include administrators"（暂行期 admin 要能 override 救火）。

## 验收

详见 [V-009](./V-009.md)：开一个不带 gate 的 PR，确认被 ruleset 拦下。
