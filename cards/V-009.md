# V-009 — 不带 gate 的 PR 被 ruleset 拦下

```yaml
id: V-009
title: 开一个不带 gate 的 PR，确认被 branch ruleset 拦下
type: Verify
role: verify
tier: standard
charter: ["G0"]
paths:
  - product-x/.github/
acceptance:
  - product-x branch ruleset "Require status checks" 非空（≥4 个 gate）
  - 开一个故意不带 gate 的 PR（如跳过 CI、空 commit）
  - PR 被 ruleset 拦下，无法合并（Merge 按钮禁用或报错）
  - ruleset 配置记录可查（截图/SETTINGS.md）
verify_target: C-009
depends_on: [C-009]
ready: false
status: pending
```

## 前置依赖检查

- [C-009](./C-009.md) 必须先 done（ruleset 已配）。
- 若 C-009 未 done → **不要开始**。

## 验证步骤

1. 确认 [C-009](./C-009.md) done，ruleset 已配 ≥4 gate。
2. 开一个测试 PR：空 commit 或 `[skip ci]`，故意不带 gate。
3. 客观记录：
   - PR 是否被 ruleset 拦下？
   - Merge 按钮状态（禁用/报错文案）？
   - ruleset 配置记录在哪？
4. 逐条对 acceptance 记 PASS/FAIL。
5. 全 PASS → VERDICT=PASS；任一 FAIL → 建 F-0NN。
6. 验证完关闭测试 PR。

## 禁止

- 不要用 admin override 强行合并测试 PR（要验 ruleset 真拦住）。
- 不要把测试 PR 留着不关（污染 repo）。
